# Title Prefixer

브라우저 탭 제목에 프리픽스를 붙이거나, URL 별로 지정한 제목으로 바꿔 주는 크롬(웨일) 확장입니다.
탭이 많을 때 `ps s dev`, `icms prod` 처럼 짧은 이름으로 바로 구분할 수 있습니다.

현재 버전: **1.1.0**

## 동작

탭이 열리거나 제목이 바뀔 때마다 아래 순서로 처리합니다.

1. **URL 규칙** — 위에서부터 처음 맞는 규칙의 제목으로 탭 제목을 통째로 바꿉니다.
2. **제외 키워드** — 원래 제목에 키워드가 들어 있으면 그대로 둡니다.
3. **프리픽스** — 그 외 모든 http(s) 탭에 `프리픽스 + 원래 제목 (+ | 26.10.01 (목) 09:30)` 형태로 붙입니다.

- 원래 제목을 기억해 두므로 설정을 바꿔 다시 적용해도 프리픽스가 겹쳐 붙지 않습니다.
- 확장을 끄면 열려 있는 탭의 제목이 원래대로 돌아갑니다.
- 설정을 저장하면 열려 있는 탭에도 바로 반영됩니다.
- 날짜·시각은 페이지를 처음 처리한 시각으로 고정됩니다.

## 설치

1. 이 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/maeng-jin/title-prefixer.git
   ```
2. `chrome://extensions` (웨일은 `whale://extensions`) 를 열고 **개발자 모드** 를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** 를 눌러 저장소 폴더를 선택합니다.

업데이트할 때는 `git pull` 후 확장 목록에서 새로고침(↻) 버튼을 누릅니다.

## 사용법

### 팝업 (툴바 아이콘)

- 확장 켜기 / 끄기
- 현재 탭에 어떤 규칙이 적용되고 있는지 확인
- 현재 탭에 맞는 규칙이 있으면 바로 **수정·삭제**, 없으면 **이 페이지 규칙 추가**
  (URL 패턴은 `origin + path` 가 미리 채워집니다)
- **설정 열기** 로 관리 페이지 이동

### 관리 페이지

| 영역 | 내용 |
|---|---|
| 기본 동작 | 사용 여부, 프리픽스, 날짜·시각 붙이기, 미리보기 |
| URL 규칙 | 사용 여부 · 매칭 방식 · URL 패턴 · 탭 제목 편집, `⠿` 를 끌어서 우선순위 변경 |
| 규칙 테스트 | URL 을 입력하면 어떤 규칙이 적용되는지 표에서 강조 |
| 제외 키워드 | 키워드 추가·삭제 |
| 내보내기 / 가져오기 | 설정 전체를 JSON 파일로 백업·복원 |
| 초기화 | 처음 설치했을 때의 규칙·키워드로 되돌리기 |
| 테마 | 시스템 / 라이트 / 다크 |

바꾸는 즉시 자동 저장됩니다.

#### 매칭 방식

| 방식 | 의미 | 예 |
|---|---|---|
| 포함 | URL 에 패턴이 들어 있으면 | `papi.dev.cats4me.net/swagger-ui` |
| 시작 | URL 이 패턴으로 시작하면 | `https://gw.danbiedu.co.kr/mail` |
| 정규식 | URL 이 정규식에 맞으면 | `^http://localhost:80\d0/swagger-ui` |

더 구체적인 URL 을 위에 둬야 합니다. 예를 들어 `gw.danbiedu.co.kr/mail` 규칙은 `gw.danbiedu.co.kr` 보다 위에 있어야 합니다.

## 설정 파일 형식

내보내기 파일은 아래 형태입니다. 가져오기는 이 형식 외에 `{ "URL": "제목", ... }` 형태의 단순 맵도 받습니다(이 경우 규칙만 교체).

```json
{
  "enabled": true,
  "prefix": "회사 - ",
  "appendDateTime": true,
  "rules": [
    { "id": "r...", "enabled": true, "match": "contains", "pattern": "https://parents.dev.cats4me.net", "title": "ps dev" }
  ],
  "excludedKeywords": ["CATS-", "통합컨텐츠"]
}
```

설정은 `chrome.storage.local` 에 저장됩니다. (`sync` 는 항목당 8KB 제한이 있어 규칙이 많아지면 저장이 실패하므로 쓰지 않습니다.)
다른 PC 로 옮길 때는 내보내기 / 가져오기를 사용하세요.

## 구조

```
manifest.json
background.js        탭 이벤트 처리, 제목 변경 함수를 탭에 주입
common/config.js     설정 저장·불러오기, 기본값, 규칙 매칭 (모든 화면 공용)
common/theme.css     색상 변수 (라이트/다크)
common/theme.js      테마 적용
options/             관리 페이지
popup/               툴바 팝업
```

빌드 과정 없이 소스 그대로 로드합니다.
